Keyring

Named testnet identities kept in this browser. Add a key under a name here, pick it from any app that imports the module.

Keys are stored plain in localStorage. Testnet only. Never add a key that holds real coins.

Use it from an app

import { list, get, add } from 'https://melvincarvalho.github.io/keyring/keyring.js';

for (const k of list()) console.log(k.name, k.priv);   // priv is 64 hex chars
const alice = get('alice');
window.addEventListener('keyring', () => { /* changed in this tab */ });
window.addEventListener('storage', () => { /* changed in another tab */ });

Every app on the same origin sees the same keyring. Apps on other origins each have their own copy, so export and import to move keys across.
